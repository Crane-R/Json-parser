# JSON 万能解析器

免安装的 Windows 桌面工具。所有数据在本机处理，无需联网，也无需安装 Python。

## 使用

双击 `output/JSON万能解析器-0.0.6.exe`。粘贴内容后自动解析；也可以拖入文本文件，或点击「打开文件」多选导入。键入、撤销、替换内容与切换解析选项也会自动刷新结果。

- 浅色紧凑双栏界面。输入与结果文本区合计占窗口客户区至少 80%，在最小尺寸 1060×800、默认尺寸 1320×900 和 1600×1000 下后台验证。移除载入示例入口。
- 可复制整个结果或单个节点、复制 JSON 路径、搜索文本、压缩输出、按键排序、保存 UTF-8 JSON。
- Ctrl+Enter / F5 解析，Ctrl+O 打开，Ctrl+S 保存；Ctrl+F 展开查找面板，Ctrl+H 直接进入替换，Esc 关闭面板。
- 点击顶部「+」或按 Ctrl+T 新建标签页，点击「×」或按 Ctrl+W 关闭当前页；Ctrl+Tab / Ctrl+Shift+Tab 切换下一页 / 上一页，鼠标滚轮横向浏览标签。
- 每个标签页独立保留输入、解析结果、解析选项、查找替换、撤销记录和结果视图；切换页面时，其他页面仍会自动解析。多选或拖入多个文件时分别打开标签页，已有内容不会被覆盖。
- 标签页仅存在于当前进程内存，关闭页签后销毁，关闭程序后所有页签全部销毁；不保存会话、不自动恢复。下次启动只有一个空白页，需要保留结果时请主动导出 JSON。
- 工具栏和按需显示的查找面板共用，绑定到当前页；新建页面不会重置全局缩放或重绘全部旧页面。各页的选项、查找词、替换词和面板展开状态仍独立保留。
- 修改输入或解析选项后，旧结果立即清除；停顿 320 ms 自动解析。后台忙碌时会在完成后继续处理最新输入，避免复制过期数据。

## 查找与替换

主界面默认不显示查找替换控件。在解析结果区按 Ctrl+F，结果编辑区内展开浅色查找面板，先显示查找输入、当前项 / 总数和前后跳转。查找计数随内容、查找词、范围和大小写选项自动更新；Enter 查找下一项，Shift+Enter 查找上一项，跳转到末尾后循环。

点击面板中的「替换」模式，才会显示替换输入框、「替换」和「全部替换」按钮；切回「查找」会收起这些控件。Ctrl+H 可直接展开替换模式，Esc 或「×」关闭整个面板并清除查找高亮。面板显示在当前查找范围所在的编辑区内，不额外弹出窗口，也不占用常驻底栏。

在原始输入区按 Ctrl+F 时查找输入，面板中也可以切换「结果 / 输入」。每个标签页独立保留查找词、替换词和展开状态；切到新标签页时默认隐藏面板。

使用普通文本匹配，不把正则字符或替换文本中的反斜杠解释为特殊语法。空替换文本表示删除匹配内容。计数与导航覆盖全部匹配；为保持流畅，同时高亮前 2000 项及当前项。

替换输入后自动重新解析，可以用输入区的撤销恢复。替换结果后校验标准 JSON，并同步结构树、计数、复制与导出；如果替换会导致 JSON 无效，则保留原结果，在处理说明中提示。

## 兼容范围

支持标准 JSON、JSON5、Python 字面量、HTML 实体、多层 JSON 字符串转义、XML 中包裹的 JSON、CDATA、连续 JSON、JSONL 对象/数组、日志中的 JSON 对象/数组、Markdown 代码围栏、JSONP、变量赋值、URL 百分号编码、UTF-8 Base64 数据、YAML、CSV/TSV 和 URL 查询参数。

对于缺少引号、逗号、括号等不完整 JSON，会尝试修复，并在「处理说明」中提示。普通文本会输出为 JSON 字符串，保留原文；不能从无结构的文字可靠推断出业务字段。

参考数据中的 `<Response>{&quot;code&quot;:0,...}</Response>` 会自动移除外壳、还原转义。同一个文件中的多个 Response 会形成 JSON 数组。项目自带参考文件已验证为两个响应，分别包含 5 条和 15 条 records。

也支持 `Respon1&quot;data&quot;:{...},&quot;ok&quot;:true}\\</Response>` 这类外壳和起始边界损坏的 Response：解码实体、补齐对象左边界、清除尾部外壳，保留现有字段。处理说明会提示修复，丢失的 code、msg 等字段不会凭空补造；严格模式不进行此恢复。

## 选项与转换规则

- **严格模式**：只接受标准 JSON，不进行兼容转换；保留顶层 JSON 字符串。
- **展开字段中的 JSON 字符串**：默认关闭。开启后，会将字段内可识别的结构化字符串继续解码为对象或数组，可能改变字段类型。
- CSV/TSV 首行作为表头，单元格保留字符串，避免丢失 `001` 的前导零；重复或空表头按二维数组保留。
- YAML 按安全加载器规则解释数字、布尔值和日期，日期输出为 ISO 字符串。
- 普通 XML 保留根标签，属性前缀为 `@`，文本使用 `#text`，重复子节点变为数组。混合文本合并；相互交错的不同标签顺序不保留。JSON 承载标签可自动解包。
- JSON 中的重复键保留最后值并提示；NaN / Infinity 转为 null 并提示。大整数使用 Python 整数，避免 JavaScript 常见的大整数精度丢失。
- 日志提取会省略 JSON 之外的日志文本，并显示提示。启发式修复请核对业务数据，无法可靠恢复已丢失的内容。
- 支持 UTF-8、带 BOM 的 UTF-8/UTF-16/UTF-32、常见无 BOM UTF-16、GB18030，并尝试检测其他文本编码。其他编码识别为启发式结果。
- 单个文件或输入上限约 512 MB 字符（不再有 20 MB 硬限制）。标准 JSON 走快路径、不受节点数约束；JSON5 / YAML / XML / CSV 仍受 2000 万节点上限，数据结构 150 层、外壳解包 12 层。结构树每次加载 250 项，双击「加载更多」继续浏览。
- 超大结果（超过 24 MB）在编辑框里只渲染前 24 MB 预览并在结尾注明，完整内容用「导出 JSON」保存，避免界面卡住。超过 40 万字符不再逐字符着色、超过 200 万字符不再逐处标注匹配，保证大文件下依然跟手。

## 命令行

在 PowerShell 中可使用：

```powershell
$process = Start-Process -FilePath '.\output\JSON万能解析器-0.0.6.exe' -ArgumentList '--input "参考数据.txt" --output "结果.json" --report "报告.json"' -WindowStyle Hidden -Wait -PassThru
$process.ExitCode
```

可加 `--strict`、`--decode-nested`、`--compact`。成功返回 0，失败返回 1；建议通过 `--report` 获取错误或转换提示。命令行不会覆盖输入文件。也可把文件拖到 exe 图标上打开。

## 环境与构建

成品为 Windows x64 单文件 exe，当前在 Windows 11 x64 上完成测试。无须安装运行库或 Python；启动时会在系统临时目录释放运行组件，退出后自动清理。仅需分发 exe 即可运行。首次启动通常比后续操作慢。

源码使用 Python 3.13 + CustomTkinter，文件拖入使用 tkinterdnd2。成品输出目录 `output` 仅存放带版本号的免安装 exe，每个版本都是独立单文件，并保留旧版本；不附带说明书、配置或数据文件。测试报告和构建中间文件存放在 `build`。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe build.py
```

`build.py` 先运行回归测试，生成图标与 Windows 版本资源，再打包单文件 exe。打包后会在完全隐藏窗口的模式下验证自动解析、输入更新、切换选项、语法高亮、结构树、查找计数、替换、标签页隔离、关闭解析中的页面、多文件导入、退出销毁与编辑区面积；通过后才发布到 output，保留旧版本，仅重新构建同一版本时覆盖该版本 exe。其他未知文件不会自动删除，构建会提示先移出。

## 版本管理

`VERSION` 是版本号唯一来源，采用 `主版本.次版本.修订号`，当前为 `0.0.6`。界面、exe 文件名、Windows 文件属性和命令行报告自动使用同一版本。每次发布在 `CHANGELOG.md` 记录更新。

```powershell
.\.venv\Scripts\python.exe versioning.py --bump patch
.\.venv\Scripts\python.exe build.py
```

上述命令会将版本更新到 `0.0.7` 并构建。`--bump minor` 和 `--bump major` 分别递增次版本、主版本，并清零后续段。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --self-test build\gui-smoke.json
```

打包后可使用 `JSON万能解析器-0.0.6.exe --self-test 报告路径.json` 后台验证；自检窗口始终隐藏，不操作用户剪贴板。
